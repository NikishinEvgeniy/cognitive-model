# Визуальное формирование модели
Здесь собраны функционалы, характеризующие "Визуальное формирование модели"
## Визуализация модели по графу достижимости
**Сценарий** - пользователь задает граф достижимости в веб интерфейсе, при этом он формируется для дальнейшей обработки
**Инструменты**
- Cytoscape.js - данная библиотека позволяет на фронте сделать визуальный редактор для графа и получить его матрицу достижимости
